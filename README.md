# Interview Starter

This repository contains starter options for interview exercises.

### Backend (API)

- `nestjs/` - NestJS + TypeORM + SQLite
- `expressjs/` - Express + TypeScript + SQLite

### Frontend

All frontend starters are blank templates built with Vite + Tailwind CSS v4 + Prettier.

- `react/` - React + Vite + Tailwind CSS
- `vue/` - Vue 3 + Vite + Tailwind CSS
- `vanilla/` - Vanilla JS + Vite + Tailwind CSS

Pick one stack and work inside that directory.

## Option 1: NestJS

Use this if you want a structured framework with modules, decorators, and built-in patterns.

- Folder: `nestjs/`
- Start command: `npm run start:dev`
- Docs: `nestjs/README.md`

Quick start:

```bash
cd nestjs
npm install
npm run start:dev
```

## Option 2: ExpressJS

Use this if you want a lightweight setup with minimal framework abstractions.

- Folder: `expressjs/`
- Start command: `npm start`
- Docs: `expressjs/README.md`

Quick start:

```bash
cd expressjs
npm install
npm start
```

## Frontend options

The `react/`, `vue/`, and `vanilla/` folders are blank frontend starters. They each use Vite,
Tailwind CSS v4, and Prettier, and serve on `http://localhost:5173` by default.

Quick start (swap in `react`, `vue`, or `vanilla`):

```bash
cd react
npm install
npm run dev
```

See each folder's `README.md` for details.

## Notes

- Backend projects run on `http://localhost:3000`; frontend starters run on `http://localhost:5173`.
- Each option includes its own project-specific documentation.
